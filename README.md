# SyncScope

**让任意 Syncthing 客户端具备选择性同步——而它自己不参与同步。**

手机或电脑空间有限时，Syncthing 往往要求你同步整个共享文件夹。SyncScope 通过编辑目标客户端的 `.stignore` 忽略规则，让你只保留勾选的内容。

SyncScope 本身**不运行同步引擎**，只是一个远程配置工具：连上目标客户端，读取目录结构与现有忽略规则，以树形界面供你勾选，然后把规则写回去。

---

## 功能特点

- **树形勾选**：任意层级展开，文件夹或单个文件都能勾选
- **三态复选**：子项部分选中时，父项显示「－」
- **随时切换**：可在「选择性同步」与「全部同步」之间切换，选择集会保留
- **安全删除**：取消勾选时先检查远端是否仍持有该文件
  - 远端有副本 → 直接删除本地文件
  - 远端无副本 → 提示风险，可选「保持勾选」或「强制删除」
- **写入后回读校验**：避免"看起来成功、实际没生效"
- **两种连接方式**（混合方案）

## 连接方式

| | REST API（推荐） | 共享目录 SMB/FTP（降级） |
|---|---|---|
| 目录树 | 能看到**远端有、本机还没下载**的文件 | 只能看到本机已存在的文件 |
| 主动触发重新扫描 | 支持 | 不支持，只能等目标客户端自己的 watcher |
| 前置条件 | 目标客户端开启「Web UI 远程访问」并提供 API key | 目标设备已开启 SMB/FTP 服务 |

官方 Android 客户端默认只监听 `127.0.0.1`，连不上；Syncthing-Fork 自带「Web UI 远程访问」开关可以打开。这时共享目录通道就是备选路径。

## 使用步骤

1. 打开 SyncScope，选择连接方式
2. REST：填地址（如 `192.168.1.10`）、端口（默认 `8384`）、API key
   共享目录：点「选择共享目录」，选中目标文件夹
3. 选中要配置的共享文件夹
4. 在树里勾选想同步的内容，点「保存」

## 实现要点（均经真实内核验证）

规则生成不是简单地"放行勾选的、忽略其余"。双节点端到端实测确认了以下约束：

1. **不能用单条全局兜底**：`*` 或 `**` 拦不住"父目录被 `!` 放行"的深层路径，必须给每个被下钻的目录显式补一条"忽略其余子项"
2. **顺序敏感**：「放行所需 → 忽略其余 → 放行目录本身」的顺序不能颠倒，否则忽略对子项失效
3. **API 写入格式**：`POST /rest/db/ignores` 的 body 必须是 `{"ignore": [...]}`，纯字符串数组无效
4. **删除已忽略的文件不会传播到远端**（Syncthing 默认语义），本地删除是安全的；但前提是规则确实覆盖了该文件

规则生成算法移植自经真值验证的实现，本机可编译并跑断言（`verify/VerifyPatterns.java`）。
